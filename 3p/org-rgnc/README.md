# org-rgnc
Unified RGNC Monorepo

This monorepo contains 14 integrated research repositories from the RGNC organization, focused on membrane computing, P systems, and GPU-accelerated simulations.

## Repositories

### Virus Machines and Computing
- **echo-virus-machines** - Echo virus machines implementation
- **virusmachines** - Framework for virus machines computation

### GPU Computing Infrastructure  
- **gpucomputing** - Information to configure the access to our servers for GPU computing

### P Systems Simulators
- **sparse_snp** - A simulator of Spiking Neural P systems for GPUs using a sparse matrix representation
- **abcd-gpu** - GPU simulator of Population Dynamics P systems
- **pcuda** - GPU simulator of P systems with active membranes
- **tspcudasat** - GPU simulator of a family of tissue-like P systems with cell division solving SAT in polynomial time
- **pcudasat** - GPU simulator of a family of recognizer P systems with active membranes solving SAT in linear time
- **creation-ccc** - Software for simulating polarizationless P systems with symport/antiport rules and creation rules

### Programming Languages and Tools
- **plingua** - The P-Lingua language for Membrane Computing

### Enzymatic Numerical P Systems
- **enps_dwa** - A C++ ROS simulator for reactive social robot navigation based on Enzymatic Numerical P systems
- **enps_rrt** - Enzymatic Numerical P systems with Rapidly-Exploring Random Trees
- **renpsm_openmp** - Simulation of Rapidly-Exploring Random Trees in Membrane Computing with P-Lingua and Automatic Programming
- **renpsm** - A software simulator for Random Enzymatic Numerical P Systems with Shared Memory (RENPSM)
