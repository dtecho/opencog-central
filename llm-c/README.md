
# LLM.C Implementation

This directory contains a complete implementation of the llm.c framework integrated with OpenCog's cognitive architecture.

## Structure

- `src/` - Core implementation files
- `include/` - Header files
- `examples/` - Example programs and demonstrations
- `tests/` - Test suite
- `build/` - Build artifacts (generated)

## Building

```bash
cd llm-c
mkdir -p build
cd build
cmake ..
make
```

## Usage

See examples/ directory for usage examples.
